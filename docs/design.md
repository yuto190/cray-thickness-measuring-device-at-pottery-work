# 高台削り用 粘土厚み測定器 設計書 (v0.1)

作成日: 2026-11-11 / 状態: 概念設計(未試作・数値は計算値)

## 1. 目的

高台削り(半乾燥=レザーハード状態の作品を伏せて削る工程)の途中で、
底および腰の土の残り厚みを **作品を傷つけずに・外側から** 数値で確認できるようにする。

- 削りすぎ(穴あき)の防止
- 削り残し(重い器)の防止

## 2. 測定方式の検討

| 方式 | 原理 | 半乾燥粘土への適性 | 自作難度 | 判定 |
|---|---|---|---|---|
| **磁気式(ホール素子)** | 内側に置いた磁石の磁界を外側のセンサで測り、距離に換算 | 粘土は非磁性で水分の影響をほぼ受けない | 低 | **採用** |
| 超音波パルスエコー | 反射波の往復時間 | 多孔質・含水で減衰が大きく、接触媒質(水・ジェル)が必要。薄肉(3〜10 mm)は MHz 帯の高速回路が必要 | 高 | 不採用 |
| 静電容量式 | 誘電率変化 | 含水率に強く依存し、乾燥の進行で値が動く | 中 | 不採用 |
| 渦電流式 | 導電体までの距離 | 内側に金属板が必要。磁気式に対する利点なし | 中 | 不採用 |
| 針刺し(従来法) | 針を貫通させて深さを読む | 確実だが穴が残る | — | 比較用の基準 |
| 寸法差(従来法) | 伏せる前に「内側の深さ」と「外側の高さ」を測り差を取る | 確実だが底中心のみ、削り途中の確認が煩雑 | — | 校正・検証に併用 |

磁気式は工業用の肉厚計(オリンパス Magna-Mike 等)と同じ原理で、
非磁性体の厚み測定として実績がある方式である。

## 3. 測定原理

内側の面に球形ネオジム磁石(ターゲット)を当て、外側の面にホールセンサ(プローブ)を当てる。
一様磁化した球の外部磁界は純粋な双極子磁界になり、軸上では

```
B(r) = (2/3) · Br · (R / r)^3
  Br : 残留磁束密度 (N35 級で約 1.2 T)
  R  : 球の半径
  r  : 球の中心からセンサ素子までの距離 = R + 厚み d + センサのオフセット
```

距離の3乗に反比例するため、薄いほど感度が高い(=穴あき直前ほど精密に測れる)。

### φ10 mm 球(R = 5 mm, Br = 1.2 T)での計算値

| 厚み d [mm] | 磁束密度 B [mT] | 感度 \|dB/dd\| [mT/mm] |
|---|---|---|
| 3 | 195 | 73 |
| 5 | 100 | 30 |
| 8 | 46 | 10.5 |
| 10 | 30 | 5.9 |
| 15 | 12.5 | 1.9 |
| 20 | 6.4 | 0.77 |

(センサのパッケージ内オフセット約 1 mm は無視した概算。実機では校正で吸収する)

センサ分解能を 0.065 mT/LSB(TMAG5273 の ±133 mT レンジ・12 bit 相当)とすると、
理論分解能は d = 10 mm で約 0.01 mm、d = 20 mm で約 0.08 mm。
実際の精度は分解能ではなく **位置合わせ誤差** で決まる(§7)。

## 4. 目標仕様

| 項目 | 目標値 | 備考 |
|---|---|---|
| 測定範囲 | 3〜20 mm | 高台削りで問題になる範囲 |
| 精度 | ±0.5 mm(3〜12 mm)、±1 mm(12〜20 mm) | 校正後。試作で検証する |
| 表示分解能 | 0.1 mm | |
| 応答 | 10 回/秒以上 | プローブを滑らせてピークを探すため |
| 表示 | 現在値・最小値ホールド・芯ずれインジケータ | |
| 警告 | 設定厚み以下でブザー | 例: 4 mm 以下 |
| 電源 | USB モバイルバッテリー または 単4×3 | 消費電流 50 mA 以下の見込み |
| 耐環境 | プローブは防水(泥水・削りカス)、本体は防滴ケース | |
| 作品への影響 | 傷・跡を付けない | プローブ先端は R 付き樹脂 |

## 5. システム構成

```
 [作品(伏せた状態)]
   内側: ターゲット磁石(φ10 ネオジム球)… 台座で内底に軽く当てる
   ─────── 粘土 ───────
   外側: プローブ(3軸ホールセンサ, 樹脂封止)
            │ I2C (4芯ケーブル 約1 m)
        [本体] Raspberry Pi Pico ── OLED 表示
                              ├─ ブザー
                              └─ ボタン×2(ゼロ/校正, ホールド解除)
```

### 5.1 プローブ

- センサ: **TI TMAG5273A2**(3軸ホール、I2C、±133 / ±266 mT レンジ切替)のモジュール基板。
  - 3軸にする理由: 軸方向成分と横方向成分の比から「ターゲットの真上にいるか」が判定でき、
    芯ずれによる誤差(厚く見える方向=危険側)を検出・補正できる。
- 代替(簡易・安価): 1軸アナログの **DRV5055A4**(±169 mT)を Pico の ADC で読む。
  この場合はプローブを動かして最大値(=真上)を探すピークホールド方式とする。
  - 注意: DRV5055 は末尾の型番で感度が違う。A1(±21 mT)は本用途では飽和するため不可。
- 構造: ペン型。先端にセンサを置き、エポキシまたは熱収縮チューブで封止。
  先端面からセンサ素子までの距離を固定する(校正の前提)。

### 5.2 ターゲット(内側の磁石)

- φ10 mm ネオジム球(約 3.9 g)。球にする理由: 磁界が理想的な双極子になり計算と合いやすい。
- 作品を伏せると内底は「天井」になるため、磁石を保持する工夫が必要。
  - **第1段階(底中心のみ)**: ろくろ中心にスポンジ柱+磁石の台座を置き、その上に作品を伏せる。
    内シッタ(内側から支える湿台)を使う場合は、その頂部に磁石を埋め込む。
    磁石の向き(極)を固定できるので、最も再現性が高い。
  - **第2段階(腰・高台脇も測る)**: プローブ先端に鉄片を入れ、磁石を引き付けて追従させる。
    概算では、理想的な鉄板に対する吸引力は厚み 10 mm で約 19 gf、15 mm で約 6 gf。
    球の自重 3.9 gf に対して 12 mm 超では余裕が小さく、実験での確認が必要(未検証)。

### 5.3 本体

- Raspberry Pi Pico(MicroPython)。校正データの記録や解析を Python で行える。
- 表示: 0.96 インチ OLED(SSD1306, I2C)。
- 校正テーブルは Pico のフラッシュに JSON で保存。

### 5.4 ソフトウェア(概要)

1. センサから Bx, By, Bz を取得(平均化あり)
2. 起動時/ボタンでゼロ点(磁石なしの環境磁界)を記録して差し引く
3. |B| を校正テーブル(対数補間)で厚みに変換
4. 横成分/軸成分の比で芯ずれを表示。許容内の値のみ「確定値」として最小値ホールド
5. しきい値以下でブザー

## 6. 校正方法

理論式に頼らず、**実測の校正テーブル** を使う(磁石の個体差・センサ位置誤差を吸収するため)。

1. 非磁性のスペーサ(アクリル板・プラ板など、ノギスで実測)を 2〜20 mm まで重ねて各点の |B| を記録
2. 実際の粘土板(同じ土・同じ乾燥度、厚みをノギスで実測)でも数点確認し、スペーサ校正との差を見る
3. 最後に不要な試作品で「測定 → 針刺し/切断して実測」の照合を行う

## 7. 誤差要因と対策

| 要因 | 影響 | 対策 |
|---|---|---|
| 芯ずれ(プローブが磁石の真上にない) | 厚み 15 mm で横 2 mm ずれると約 +0.3 mm **厚く** 表示(危険側) | 3軸で芯ずれ検出、最小値ホールド |
| プローブの傾き | 同上 | 先端を平ら気味にして面に沿わせる |
| 磁石の向き(極が傾く) | 表示が厚く出る | 台座に固定、または球+鉄片で自己整列 |
| 周囲の鉄・磁界(ろくろの軸・モーター、鉄製カンナ) | オフセット | 測定位置でゼロ取り。測定時は鉄工具を離す |
| 赤土など鉄分の多い土 | 理論上は小さい(酸化鉄は弱磁性)が未検証 | §6-2 の粘土板校正で確認 |
| 温度 | ネオジムは約 −0.12 %/℃。10 ℃差で厚み換算 0.1 mm 未満 | 無視可 |
| 地磁気(約 0.05 mT) | 20 mm でも 0.1 mm 未満 | ゼロ取りで除去 |
| 曲面(内側の R) | 球は点接触なので影響小。外側プローブの浮きが誤差になる | プローブ先端を小径にする |

## 9. 開発ステップ

1. **原理確認**: センサモジュール+Pico をブレッドボードで接続し、アクリル板越しに B–距離カーブを取得。§3 の計算値と比較
2. **粘土での確認**: 実際の土の板で校正カーブの差、再現性(同一点 10 回測定のばらつき)を評価
3. **第1段階の実機**: プローブ封止、台座ターゲット、表示・ブザー。底中心厚みの測定を実作業で試す
4. **第2段階**: 追従ターゲット方式で腰・高台脇の測定を検討(吸引保持力の実験から)

ステップ 1・2 は部品 #1, #2, #4, #10 のみ(約 3,000〜4,000 円)で実施でき、
ここで目標精度に届かないと分かれば損失を小さく止められる。

## 10. 未確定事項(試作で確認が必要)

- 実際の位置合わせ込みの総合精度(目標 ±0.5 mm は未検証の設計目標)
- 追従ターゲット方式の保持力と、内面に転がり跡が付かないか
- ろくろ本体の鉄部品・モーターによる磁界の乱れの大きさ
- 鉄分の多い土での影響

## 11. 安全上の注意

- ネオジム磁石は心臓ペースメーカー等の医療機器、磁気カード、時計に近づけない
- 球磁石は小さく誤飲の危険があるため、子ども・ペットの手の届かない場所に保管する
- 磁石を作品の中に置き忘れたまま焼成しない(伏せる前後の個数確認を手順に入れる)
