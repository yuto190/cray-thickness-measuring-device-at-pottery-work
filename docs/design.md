# 高台削り用 粘土厚み測定器 設計書 (v0.2)

更新日: 2026-11-11 / 状態: 概念設計(未試作・数値は計算または見積り)

v0.1 からの変更: 「内側に磁石を当て続ける」方式は実作業で保持が困難なため **不採用**。
要求条件を見直し、方式を再選定した。

## 1. 目的と要求条件

高台削りの途中で、土の残り厚みを作品を傷つけずに外側から数値で確認する。

| # | 要求 | 根拠 |
|---|---|---|
| R1 | ろくろ直置き(口縁を下にして粘土で固定)で使える | 利用者の多数がこの方法 |
| R2 | シッタ使用時にも使えることが望ましい | 本人は両方使う |
| R3 | 底だけでなく **壁の基部(腰)** も測れる | 余分な土が残りやすい場所 |
| R4 | 測定中、内側で何かを保持・位置合わせする必要がない | v0.1 の反省 |
| R5 | 秋月・マルツ・モノタロウ等で入手できる部品 | |

## 2. 方式の再検討

内側に手が届かない状態で厚みを知る方法は、原理的に次の4系統に限られる。

| 方式 | 原理 | 内側の準備 | 腰の測定 | 物理的な確実性 | 判定 |
|---|---|---|---|---|---|
| **B. 箔ライナー+渦電流** | 伏せる前に内面へアルミ箔を貼り、外側のコイルで箔までの距離を測る | 箔を貼る(約30秒) | 可(分解能に制約) | 高(膜厚計と同じ原理) | **第1候補** |
| **A. 寸法差(高さ基準)** | 伏せる前に内側の深さを測り、削り中は外面の高さを測って差を取る | なし(事前に1回測る) | 困難(内側形状の記録が必要) | 高(単純な幾何) | **確実な保険(底のみ)** |
| D. 4探針抵抗法 | 表面に当てた4本の電極で電気抵抗を測る。裏が空気(絶縁)なので薄いほど抵抗が上がる | なし | 形状の影響大 | 中(水分勾配の影響が未知) | 実験候補 |
| C. 超音波パルスエコー | 裏面からの反射時間 | なし | 可 | 不明(半乾燥粘土での実績を確認できず) | 保留 |

補足:

- **C 超音波**: 文献・製品情報を調べたが、半乾燥粘土で市販の厚さ計が使えるという根拠は見つからなかった。
  シャモット入りの土では散乱が大きいと予想される。自作は高速回路が必要で難度が高い。
  市販の厚さ計(1〜3万円)を借りて試せる機会があれば、試す価値はある。
- **D 4探針**: 地質調査の電気探査と同じ原理で、探針間隔を2種類にすれば抵抗率(水分)の影響を打ち消せる。
  ただし粘土は表面から乾くため厚み方向に抵抗率の勾配があり、精度への影響は実験しないと分からない。
  ピンの小さな跡も残る。
- ミリ波レーダー・静電容量は、含水粘土が導電性で損失が大きいため不適。

## 3. 第1候補: 箔ライナー+渦電流方式 (B)

### 3.1 原理

塗装の膜厚計(非鉄金属上の非導電皮膜を測るタイプ)と同じ。
粘土を「皮膜」、内面に貼ったアルミ箔を「下地金属」とみなす。

- プローブのコイルを LC 発振させる(約 1 MHz)
- コイルが箔に近づくと、箔に渦電流が流れてコイルのインダクタンスが下がり、発振周波数が上がる
- 周波数の変化量を校正テーブルで距離(=粘土の厚み)に換算する

箔は面で覆うので、**磁石方式で問題だった位置合わせが不要**(R4)。
箔を貼った範囲なら底でも腰でも測れる(R3)。直置きでもシッタでも使える(R1, R2)。

### 3.2 成立性の概算

- 家庭用アルミ箔(約 11 µm)は 1 MHz での表皮深さ(約 80 µm)より薄いが、
  コイル径 25 mm では箔の遮蔽パラメータ(μ0·σ·t·ω·a)が約 30 と 1 より十分大きく、ほぼ理想導体として働く
- 半乾燥粘土の導電率(1 S/m 以下の見込み)はアルミ(3.5×10^7 S/m)より 7 桁以上小さく、粘土自体の渦電流は無視できる
- 測定できる距離はコイル直径程度まで。**3〜20 mm を測るにはコイル径 25 mm 前後が必要**
- Pico で 1 MHz を 0.1 秒数えると分解能 10 ppm。遠距離側(20 mm)でも 0.1 mm 以下の分解能は見込める。
  実際の精度は発振回路の温度ドリフトで決まる → 測定前にプローブを空中に離してゼロ取りする

### 3.3 既知の制約とリスク(要実験)

| 項目 | 内容 | 対策案 |
|---|---|---|
| 箔の密着 | 半乾燥の内面に箔が安定して貼り付くか未検証。浮くと **厚く** 表示される(危険側) | 水で湿らせて貼る。紙裏打ちの箔、濡らした紙で押さえる等を比較 |
| 空間分解能 | 測定値はコイル径程度の範囲の平均。腰の角や小さい高台では「法線方向の厚み」と一致しない | 小径コイル(φ12, 測定範囲 3〜10 mm)のプローブを別に用意 |
| 濡れた粘土との容量結合 | コイルと粘土の間の浮遊容量で周波数がずれる可能性 | 静電シールド(スリット入り箔)、同調容量を大きめにする |
| 口の狭い作品 | 手が入らず箔を貼れない | 方式 A で底のみ測る |
| 箔の取り忘れ | アルミは約 660 ℃ で溶ける | 削り後に必ず剥がす手順とする(§7) |

### 3.4 構成

```
 内面: アルミ箔(伏せる前に底〜腰に貼る)
 ─────── 粘土 ───────
 外面: プローブ(平面コイル φ25 + 発振回路, 樹脂封止)
          │ 電源・周波数出力 (3芯ケーブル)
      [本体] Raspberry Pi Pico ── OLED 表示
                            ├─ ブザー(設定厚み以下で警告)
                            └─ ボタン×2(空中ゼロ, ホールド解除)
```

- 発振回路はプローブ内に置く(ケーブルの動きで周波数が変わらないようにするため)
- コイルは手巻き(ポリウレタン銅線)、同調コンデンサは温度安定な C0G 品
- 発振は 74HCU04 またはトランジスタ1石。代案として TI LDC1612(インダクタンス測定 IC)
- ソフトは MicroPython。周波数を数え、空中値との差を校正テーブルで厚みに換算

### 3.5 校正

1. 平板に貼った箔の上に、アクリル板(ノギスで実測)を 2〜20 mm 重ねて周波数変化を記録
2. 実際の土の板(裏に箔)で数点確認し、粘土の影響(§3.3 の容量結合)の大きさを見る
3. 不要な試作品で「測定 → 切断して実測」を照合

## 4. 保険: 寸法差方式 (A, 底の厚みのみ)

直置きでは口縁がろくろ面に接するので、ろくろ面を基準にできる。

```
 底の厚み = (ろくろ面から外底までの高さ) − (口縁から内底までの深さ)
```

- 伏せる前: 口縁に定規を渡し、デプスゲージで内底までの深さを測る
- 削り中: ろくろ上に渡したブリッジ、またはスタンドに付けた高さ測定器で外底の高さを測る
- 電子工作なしでも成立する(デプスゲージ+スタンド)。物理的に確実で、粘土の状態に依存しない
- 限界: 腰は測れない。シッタ使用時は基準面が変わる(内シッタなら頂部の高さを基準にできる)。
  口縁の歪みがそのまま誤差になる

## 7. 作業手順の想定(方式 B)

1. 伏せる前に、内面の底〜腰に湿らせたアルミ箔を貼る
2. 通常どおり伏せて固定し、芯を出す
3. プローブを空中でゼロ取りし、測りたい場所に当てて厚みを読む。削りながら繰り返す
4. 削り終わったら **箔を必ず剥がす**(枚数を数えて確認)

## 8. 開発ステップ

1. **成立性実験(約 2,000〜3,000 円)**: Pico+手巻きコイル+発振回路をブレッドボードで組み、
   箔+アクリル板で周波数–距離カーブを取る
2. **粘土での実験**: 土の板の裏に箔を貼り、(a) 粘土の有無による差、(b) 箔の貼り方ごとの密着と再現性、
   (c) 実際の器の腰での読み、を確認する。ここで目標精度に届かなければ方式 A / D に切り替える
3. **実機化**: プローブ封止、表示、ブザー、ケース
4. 余力があれば小径プローブ、方式 D の比較実験

## 9. 未確定事項

- 箔が半乾燥の内面に安定して貼り付くか、どの貼り方がよいか
- 腰の角での読みと実際の厚みの関係
- 濡れた粘土による周波数ずれの大きさ
- 総合精度(§5 は未検証の目標値)

## 10. 安全上の注意

- アルミ箔を作品内に残したまま乾燥・焼成しない
- 本体・ケーブルは泥水がかからない位置に置く。電源は低電圧(USB 5 V)のみ

## 付録: 不採用とした磁気式(v0.1)

内側にネオジム球、外側にホールセンサを当てる方式。原理は成立するが、
伏せた作品の内側で磁石をプローブの真裏に保持し続けることが実作業では困難なため不採用とした。
